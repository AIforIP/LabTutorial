# 1. 科研基本功

科研能力不是“知道很多论文”，而是能够围绕一个问题收集证据、提出可检验的想法、设计实验并清楚地表达结论。对于刚入门的同学，先把基本工作流做规范，比急于追逐最新模型更重要。

## 1.1 从问题开始

一个研究任务通常经历以下循环：

```text
观察现象 → 明确问题 → 检索已有工作 → 提出假设
    ↑                              ↓
总结与表达 ← 分析结果 ← 设计并执行实验
```

好的问题至少包含三个要素：研究对象、希望理解或改善的性质、判断结果的证据。例如“研究大模型”太宽泛；“长文本分类中，截断策略如何影响少数类别召回率”就更容易设计实验。

开始前写下：

- 我究竟想知道什么？
- 什么结果可以支持或反驳我的判断？
- 已有工作解决到哪一步？
- 我的时间、数据和算力允许做到什么程度？

## 1.2 文献检索

### 构造检索词

不要只输入完整中文问题。先提取概念，再准备同义表达与英文术语：

```text
任务：文本分类 / text classification
现象：类别不平衡 / class imbalance / long-tail
方法：重采样 / resampling / reweighting
场景：法律文本 / legal documents
```

组合检索时先宽后窄。先找到综述、教程或代表论文，记录其中反复出现的术语、作者与数据集，再用这些线索继续追踪。

### 沿引用关系扩展

找到一篇关键论文后，沿两个方向阅读：

- **向后看**：参考文献中有哪些理论来源和早期代表工作；
- **向前看**：哪些后续论文引用了它，修正了什么问题。

优先使用论文主页、出版社、会议论文集、作者主页和 arXiv 等可追溯来源。二手文章适合帮助理解，但不应替代原始论文成为结论依据。

### 建立检索记录

建议用表格记录：

| 字段 | 内容 |
| --- | --- |
| 基本信息 | 标题、作者、年份、会议或期刊 |
| 研究问题 | 论文试图解决什么 |
| 方法 | 核心假设与关键步骤 |
| 实验 | 数据集、指标、基线、主要结果 |
| 判断 | 优点、局限、尚未回答的问题 |
| 关系 | 与当前课题或其他论文的联系 |

## 1.3 阅读论文

### 第一遍：判断是否值得细读

先读标题、摘要、引言、主要图表和结论。回答四个问题：

1. 论文解决什么问题？
2. 为什么这个问题重要？
3. 核心方法是什么？
4. 主要证据是什么？

如果这些问题仍无法回答，先不要陷入公式细节。检查是否缺少前置知识，或论文是否与目标真正相关。

### 第二遍：重建论证链

逐节阅读，并用自己的话写出：

```text
问题 → 现有方法缺口 → 本文假设 → 方法设计 → 实验验证 → 结论边界
```

特别关注实验中的对照组、评价指标和消融实验。论文声称的改进，是否真的被实验设计验证？平均指标提升是否掩盖了某些类别的退化？

### 第三遍：面向复现

阅读实现细节、附录和代码。列出所有会影响结果但正文可能一笔带过的因素：随机种子、数据预处理、超参数、训练步数、模型选择标准和硬件环境。

一份有效的阅读笔记不应只是复制原文。建议固定包含“我理解了什么”“我不确定什么”“我接下来要验证什么”。

## 1.4 制作研究汇报 PPT

PPT 的任务是帮助听众跟上你的论证，不是把论文压缩后贴到幻灯片上。

### 基本结构

一次论文汇报可以采用：

1. 背景与问题：为什么值得研究；
2. 现有方法与缺口：作者从哪里出发；
3. 核心方法：用一张总览图建立全局认识；
4. 关键细节：只解释理解结论必需的部分；
5. 实验与结果：说明比较是否公平、结论是否成立；
6. 局限与思考：给出自己的判断。

### 排版原则

- 一页只承担一个主要信息；
- 标题直接写结论，例如“重加权主要改善少数类召回率”；
- 图表必须标出坐标、图例、单位和你希望听众关注的位置；
- 正文使用短句，避免整段复制论文；
- 字号宁可略大，不要靠缩小文字塞入更多内容；
- 每页都问自己：如果删掉这页，会损失哪一步论证？

完成后至少完整计时演练一次。超时通常不是语速问题，而是信息选择失败。

## 1.5 使用 LaTeX 写作

LaTeX 的优势是把内容结构与视觉格式分开，尤其适合公式、交叉引用和参考文献较多的技术文档。

一个最小文档如下：

```latex
\documentclass[UTF8]{ctexart}
\usepackage{amsmath}
\usepackage{graphicx}
\usepackage{booktabs}

\title{实验报告}
\author{Your Name}

\begin{document}
\maketitle

\section{研究问题}
本文研究……

\section{方法}
交叉熵损失为
\begin{equation}
  \mathcal{L} = -\sum_{k=1}^{K} y_k \log p_k.
\end{equation}

\section{实验}
实验设置与结果……

\end{document}
```

入门阶段需要掌握：章节结构、公式环境、图片和表格、标签与交叉引用、BibTeX/BibLaTeX 参考文献。不要手工输入图号、表号和引用编号。

## 1.6 可复现实验

每次实验至少记录：

- 代码版本或 Git commit；
- 数据版本与预处理方式；
- 完整配置和随机种子；
- 软件环境与硬件；
- 训练日志、最终指标和异常现象；
- 运行命令与输出文件位置。

不要用 `final_v2_really_final.py` 管理实验。代码交给 Git，参数交给配置文件，结果放在带日期或实验 ID 的目录中。

## 本章任务

选择一篇与你感兴趣方向相关的论文，完成：

1. 一页结构化阅读笔记；
2. 一份不超过 8 页的 PPT；
3. 一次 5 分钟限时汇报；
4. 一份包含公式、图片和参考文献的两页 LaTeX 报告。
